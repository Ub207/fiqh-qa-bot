# Islamic Fiqh Q&A Assistant

An AI-powered Q&A bot grounded in classical Hanafi scholarship and Fatawa Darul Uloom Deoband.

- Fatawa Darul Uloom Deoband
- Classical Hanafi texts (Hidayah, Durr al-Mukhtar, Radd al-Muhtar, Bahishti Zewar)
